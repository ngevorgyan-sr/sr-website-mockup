# speedrun Website Mockup

Shareable production mockup with a separate glass playground and developer handoff. This repository contains built static files.

- [View the mockup](https://ngevorgyan-sr.github.io/sr-website-mockup/)
- [Developer effect demo](https://ngevorgyan-sr.github.io/sr-website-mockup/glass-kit/demo/)
- [Download the developer kit](https://ngevorgyan-sr.github.io/sr-website-mockup/downloads/speedrun-glass-effects.zip)
- [Open Glass Studio](https://ngevorgyan-sr.github.io/sr-website-mockup/glass-studio/)
- [Download Glass Studio](https://ngevorgyan-sr.github.io/sr-website-mockup/downloads/speedrun-glass-studio.zip)
- [Integration guide](glass-kit/INTEGRATION.md)

Both downloads include self-contained HTML demos: unzip and double-click. The developer kit contains the locked preset, JavaScript/CSS, readable source, React examples and types. The separate Studio contains live controls, timelines, keyframe graphs, and preset import/export. It does not save changes to this website. The main mockup and production kit contain no editor.

Capital, Customers, Talent and Residency detail links use the existing staged prototype. This is a homepage mockup.
