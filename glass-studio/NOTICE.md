# Project Handoff

This is an integration handoff for the speedrun website project. It has not been published to npm and is not offered under a new open-source license. The existing brand, font, imagery and project ownership terms continue to apply.

The glass renderer and ripple implementation are project code. The material research referenced the ybouane liquid-glass demonstration and samasante liquid-glass project; neither is installed as a runtime dependency. The separate Studio package includes art-direction controls and their source. No Figma source file or reference video is included. The production effects package remains editor-free. Demo media are the existing project poster and font, separate from the reusable runtime.
